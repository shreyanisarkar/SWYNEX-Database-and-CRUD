# SWYNEX Database and CRUD

## Project Description

A Student Management REST API developed using
Python, Flask and SQLite.

## Technologies Used

- Python
- Flask
- SQLite
- REST API
- Postman

## Features

1. Create student records
2. Read student records
3. Update student records
4. Delete student records
5. Input validation
6. Health check endpoint

## Installation

Install dependencies:

pip install -r requirements.txt

## Run Application

python app.py

## API Endpoints

GET /
GET /health
POST /api/students
GET /api/students
GET /api/students/id
PUT /api/students/id
DELETE /api/students/id
